Inline v|s Block Elements in HTML

Inline Elements

Inline elements are those that do not start on a new line and only take up as much width as necessary. They are typically used for formatting text within a block-level element. Examples of inline elements include:

  • Bold Text
  • Italic Text
  • Underline Text
  • Strikethrough Text
  • Anchor Link

Block Elements

Block elements are those that start on a new line and take up the full width available. They are typically used for structuring the layout of a webpage. Examples of block elements include:

  • Heading 1

  • Heading 2

  • Heading 3

  • Paragraph

  • Division
  • Section

Horizontal Rule

The hr element is a block-level element that creates a horizontal line across the page. It is often used to separate content or create visual breaks in a webpage.

Subscript and Superscript

The sub and sup tags are inline elements that are used to create subscript and superscript text, respectively. Subscript text is displayed slightly below the normal text line, while superscript text is displayed slightly above the normal text line.

Semantic Tags in HTML

Semantic tags are HTML elements that convey meaning about the content they contain. They help search engines and assistive technologies understand the structure and purpose of a webpage. Examples of semantic tags include:

  • Header

    • The header tag is used to define the header section of a webpage, typically containing the site title, logo, and navigation links.

  • Navigation

    • The nav tag is used to define a section of navigation links, allowing users to easily navigate through the website.

  • Main Content

    • The main tag is used to define the primary content of a webpage, which is unique to that page and not repeated across other pages.

  • Section

    • The section tag is used to define a section of a webpage, typically containing a group of related content.

  • Article

    • The article tag is used to define a self-contained piece of content that could be distributed independently, such as a blog post or news article.

  • Aside

    • The aside tag is used to define content that is related to the main content but not essential to it, such as a sidebar or pull-quote.

  • Footer

    • The footer tag is used to define the footer section of a webpage, typically containing copyright information, links to related pages, or other supplementary information.

Using semantic tags can improve the accessibility and search engine optimization (SEO) of a webpage, as they provide additional context and meaning to the content.

HTML Entities

HTML entities are special codes that represent characters that have a reserved meaning in HTML. They are used to display characters that would otherwise be interpreted as HTML code, such as <, >, and &. HTML entities are written using an ampersand (&) followed by a code or name, and ending with a semicolon (;).

Examples of HTML entities include:

  • < for the less-than symbol (<)
  • > for the greater-than symbol (>)
  • & for the ampersand symbol (&)
  • " for the double quotation mark (")
  • ' for the single quotation mark (')
  • © for the copyright symbol (©)
  • ® for the registered trademark symbol (®)
  •   for the non-breaking space ( )
  • € for the euro currency symbol (€)
  • £ for the pound currency symbol (£)
  • ¥ for the yen currency symbol (¥)
  • &heart; for the heart symbol (♥)
  • ☆ for the star symbol (★)

Using HTML entities can help ensure that special characters are displayed correctly in a webpage, and can also improve the accessibility of the content for users who rely on screen readers or other assistive technologies.
